# Cameras

#### 介绍
摄像头App等程序，对A9等摄像头模块接收视频流

#### 软件架构
基于PPPP协议的小型摄像头，包括A9


#### 安装教程

1.  A9Camera4net 为WPF版本，测试通过
2.  Camera4js 为JS版本，github有对应开源 github.com/datenstau/A9_PPPP 测试修改
3.  Camera4python 为python版本，实现PPPP协议和对应 加密解密
